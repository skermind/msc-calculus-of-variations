\addcontentsline{toc}{chapter}{Executive Summary}

\subsection*{The Problem}

In this dissertation, we explore path planning problems where the aim is to minimise cost. The cost of a path is made up of three components: terrain costs (i.e. hills), its curvature, and its length. We build upon the classical Dido problem to investigate this more complicated problem. A good analogy is planning a railway route or motorway, where infrastructure needs to be short, relatively straight, and cost-effective.


\subsection*{How the Issue Was Addressed}

We start by applying the Classical Method of the Calculus of Variations. Immediately, we find that the Classical Method leads to a fourth-order ODE that we cannot solve explicitly. This motivates us to use the Direct Method of the Calculus of Variations, which provides an existence proof.

With the confidence of knowing that a minimiser exists, we apply a numerical stochastic optimisation method called Simulated Annealing, modelled in Python. This algorithm uses randomness to search for an approximation to an optimum. We start with an initial straight-line path and apply small movements. If the new path has a lower cost, we accept the move.

\subsection*{Interpretation of Findings}

The existence proof is important, since it is not obvious that a minimising path exists. This dissertation also provides a high-level tutorial for learning how to use the Direct Method of the Calculus of Variations.

\subsection*{Recommendations and Future Work}

While the current model serves as a proof of concept, some avenues for further work are:

\begin{itemize}
\item \textbf{Real-World Data:} Use OpenStreetMap data to investigate whether the algorithm works effectively with real-world terrain and infrastructure. It would be particularly interesting to compare the routes produced by the algorithm with existing railway lines.

\item \textbf{Three-Dimensional Extension:} Increase the complexity of the terrain cost function to take elevation into account, for example when considering tunnels or bridges. This would also allow factors such as the gradient of the track to be incorporated.

\item \textbf{Systematic Parameter Tuning:} The parameters used in the numerical experiments were chosen through experimentation. A more systematic approach to selecting these parameters could be developed.


\end{itemize}
